## 👋 Sobre

Sou **Pedro Emílio Gêa Gontijo Martins**, estudante do 8º período de **Ciência da Computação** e desenvolvedor de **Automação & Inteligência Artificial**.

Este repositório foi criado no desafio **"Entrega Intermediária — Criação de Repositório com Versionamento"** do **Bootcamp I**, com o objetivo de:

- organizar meus projetos acadêmicos e pessoais em um único lugar;
- aplicar boas práticas de **versionamento com Git** e **colaboração no GitHub**;
- publicar um **site de portfólio** com **GitHub Pages**;
- integrar o portfólio ao meu **perfil do LinkedIn**.

## 💻 Como executar o site localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/PedroEmilioGea/github-page.git
   cd github-page
   ```
2. Abra o arquivo `index.html` no navegador — não é preciso instalar nada.
3. *(Opcional)* Para simular um servidor:
   ```bash
   python -m http.server 8000
   # acesse http://localhost:8000
   ```
