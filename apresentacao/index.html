03 · Versionamento com Git

Do computador ao GitHub

$ git add .
$ git commit -m "feat: adiciona projetos..."
$ git tag v1.1
$ git push origin main --tags
✔ GitHub Pages atualizado
  • Feito com o GitHub Desktop: Changes → Commit → Push.
  • Mensagens no padrão Conventional Commits (feat:, docs:, fix:).
  • Cada entrega marcada com uma tag e registrada no CHANGELOG.
InitialRepositório criado com README e GitHub Pages ativado.
