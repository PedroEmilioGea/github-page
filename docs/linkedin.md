### Passo a passo

1. **Destaques** — no perfil: **Adicionar seção → Recomendado → Adicionar destaques → Adicionar um link** → colar o link do site → título e descrição → **Salvar**.
2. **Projetos** — **Adicionar seção → Recomendado → Adicionar projetos**:
   - **Nome:** Portfólio com GitHub Pages
   - **Descrição:** Repositório com projetos acadêmicos e pessoais, versionado com Git e publicado com GitHub Pages.
   - **Competências:** Git, GitHub, HTML, CSS, JavaScript
   - **Associado a:** a formação em Ciência da Computação / Bootcamp I
   - **Mídia → Adicionar link:** link do repositório
3. **Site no contato** — **Editar introdução → Informações de contato → Site** → link do portfólio → tipo **Portfólio**.
4. **Post** — compartilhar o link do site e do vídeo, marcando a instituição.

> A prévia (imagem, título e descrição) do link aparece porque o `index.html` tem as meta tags **Open Graph** (`og:title`, `og:description`, `og:image`).
